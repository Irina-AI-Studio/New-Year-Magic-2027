# New Year Magic 2027 · v1.0

Интерактивная новогодняя открытка с фотореалистичной ёлкой, снегопадом и четырьмя пожеланиями. Игрушки открываются мышью, касанием или с клавиатуры. После четырёх пожеланий появляется праздничное поздравление с возможностью повторить сцену. На смартфонах карточки и финал располагаются под ёлкой.

Снимок опубликованной версии от коммита `838623eee4382fbd1a2e852db680e75501b1ac96`.

## Технологии

- React и Vite для интерфейса и сборки.
- Motion для появления карточек и поздравления.
- CSS и SVG для адаптивной композиции, игрушек и световых эффектов.
- Canvas 2D для снегопада и золотых искр.
- Локальные шрифты Cormorant Garamond и Manrope через Fontsource.

## Локальный запуск

Установите Node.js 22.12 или новее. Распакуйте архив, откройте терминал в папке проекта и выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, который Vite покажет в терминале. Для сборки и предварительного просмотра:

```sh
npm run build
npm run preview
```

Готовые статические файлы будут в `dist/`. Для отдельной публикации используйте новый проект хостинга и укажите `dist/` как каталог публикации. Привязка к исходному приватному сайту в архив не входит. Ключи и переменные окружения для локального запуска не требуются.

## Структура исходников

- `src/main.jsx` — состояние открытки, карточки пожеланий, счётчик и финал.
- `src/Tree.jsx` — ёлка, игрушки, гирлянда и звезда.
- `src/Snowfall.jsx` — снег и частицы.
- `src/config.js` — тексты, цвета и координаты световых точек и украшений.
- `src/style.css` — композиция, адаптивность и анимации.
- `src/assets/tree.webp` — изображение ёлки с прозрачным фоном.

Чтобы заменить изображение, обновите его исходные размеры в атрибутах `width` и `height` компонента `ChristmasTree` и при необходимости подстройте относительные координаты украшений в `src/config.js`.
